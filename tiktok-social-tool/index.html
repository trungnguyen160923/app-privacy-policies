Purpose of the Application

The Application helps users manage TikTok content workflows, including scheduling and posting videos, preparing captions and metadata, connecting a TikTok account, checking publishing status, and maintaining records needed to operate social media posting workflows.

The Application only accesses TikTok data after you authorize access through TikTok's authorization flow. The Application uses TikTok data only to provide the features you request and to operate, secure, maintain, and improve the service.
